# 개념기반 탐구 칠판

개념기반 탐구수업용 화면 칠판입니다. `index.html` 파일 하나로 동작하며, 브라우저(크롬·엣지·웨일)에서 열면 바로 쓸 수 있습니다.

- 개념 렌즈 · 날짜 · 탐구 질문 · 개념 은행 · 탐구 1~3 · 일반화 문장 배치
- 칸을 눌러 바로 타이핑, 내용은 자동 저장
- 일반화 문장에서 `( )`로 감싼 낱말은 자동으로 빨간색
- 글자를 드래그하면 빨강/파랑/밑줄/형광 서식
- 빈칸 모드: 빨간 낱말을 가리고, 누르면 하나씩 공개
- 흰 보드 / 칠판색 배경, 글꼴 4종, 글자 크기 조절, 발표 모드, 수업 저장·불러오기
